=== 5. ultraviolet Terminal, the process-terminal part ===
Terminal.Start() with the default console failed: failed to set terminal to raw mode: inappropriate ioctl for device
verdict: Terminal owns a process terminal: NewTerminal(nil, nil) builds a
         console over os.Stdin/os.Stdout, Start calls Console.MakeRaw, reads
         TERM from the process environment, and installs a SIGWINCH handler.
         A VibeShell session must use TerminalReader or its own screen model.
